# Lost and Found

A simple platform for reporting, browsing, and claiming lost or found items within a community, campus, office, or organization.

## Overview

Lost and Found helps people:
- Report an item they've **lost**
- Report an item they've **found**
- Search and browse listings to find a match
- Contact the reporter to arrange a return

## Features

- 📝 Post lost or found items with a title, description, category, location, date, and photo
- 🔍 Search and filter items by keyword, category, location, or date
- 📬 Contact / claim flow to connect finders and owners
- 🗂️ Item status tracking (Open, Claimed, Resolved)
- 🔐 (Optional) User accounts for managing your own posts
- 📱 Responsive design for mobile and desktop

## Usage

1. Create an account or sign in.
2. Click **Report Lost Item** or **Report Found Item**.
3. Fill in details: title, description, category, date, and location.
4. Browse or search existing listings to find a match.
5. Use the contact/claim option to connect with the poster.
